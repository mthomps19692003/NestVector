Release notes for the current NestVector by CoreNucApps build, including the app areas included in the first public package.

NestVector by CoreNucApps 1.0

Version 1.0 is the initial packaged release for NestVector. This release focuses on personal market tracking, configurable trend views, TSP fund history, retirement scenario planning, investment account records, and local preferences.

Version 1.0
Build 1
Package NestVector 1.0.0.0
Primary Platform Windows

Included App Areas

Stocks

Watchlist and market panels

Add ticker symbols, view quote data, review NYSE and NASDAQ summaries, and inspect top market movers.

Trends

Configurable chart dashboard

Compare up to four user-selected symbols across time ranges from one day through five years.

TSP

Thrift Savings Plan fund view

Review fund prices, recent status, compact sparklines, and detailed fund history popups.

Retirement

FERS and CSRS scenario planning

Estimate gross annuity income, include optional income rows, save scenarios, and compare reports.

Investments

Local account records

Store investment account details, sort rows, and choose which columns are visible in the table.

Preferences

Local display choices

Choose theme, currency formatting, and whether buttons show icons, text, or both.

Packaging Notes

The Windows release package is prepared as an MSIX package under the NestVector Microsoft Store artifact folder. Store licensing, installation, and updates are managed through the Microsoft Store listing when published.

The package artifact for this release is named NestVector_1.0.0.0_x64.msix.

Known Notes

  • Market quotes, index data, movers, historical series, gold, and silver data depend on upstream Yahoo Finance endpoints.
  • TSP fund data depends on the official TSP fund price history CSV source.
  • The app is informational only and should not be used as financial, tax, investment, or retirement advice.
