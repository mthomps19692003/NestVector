Technology

NestVector is built with a modern .NET application stack for cross-platform user interfaces, market data requests, custom charts, local preferences, and local SQLite records.

Core Application Stack

.NET 10

The application targets .NET 10 and uses modern C# with nullable reference types and implicit using directives enabled.

.NET MAUI

The shared application is built with .NET MAUI so market, retirement, TSP, and investment workflows can be delivered across supported platforms.

C#

C# powers page logic, data services, preferences, retirement calculations, investment storage, and chart preparation.

XAML

XAML defines Shell navigation, app pages, themed resources, layouts, controls, and reusable UI structure.

Platforms

  • Windows WinUI
  • Windows 10 version 1809 or newer
  • Windows 11
  • Android 5.0 or newer
  • iOS 15.0 or newer
  • Mac Catalyst 15.0 or newer
  • x64
  • ARM64

Data And State

SQLite

Saved retirement scenarios and investment account records are stored locally with SQLite using sqlite-net-pcl.

MAUI Preferences

Watchlists, selected trend symbols, theme, currency, button display mode, and chart ranges are persisted locally on the device.

Local First Records

Retirement and investment planning records remain on the user's device unless the user chooses to copy, back up, or share device data separately.

Market Data And Charts

HttpClient

Market, quote, trend, index, mover, gold, silver, and TSP data are retrieved over HTTP from external data sources.

System.Text.Json

Yahoo Finance responses are parsed from JSON for quotes, search suggestions, historical series, index data, and movers.

Microsoft.Maui.Graphics

Line charts and compact sparklines are drawn with MAUI Graphics for normalized trends and TSP fund history.

Data Sources

  • Yahoo Finance endpoints for stock quotes, ticker suggestions, historical trends, NYSE and NASDAQ summaries, market movers, gold futures, and silver futures.
  • Official Thrift Savings Plan fund price history CSV for TSP fund share-price history.
  • U.S. Office of Personnel Management formula concepts for FERS and CSRS gross annuity estimates.
